## A pack defect found during this phase

**T-6.02, T-6.04 and T-6.05 declare no `Read:` list in pack `05`.** The context bundler
cannot build a bundle for them, because a ticket with no Read list has no defined context
and the agent would have to guess one.

The pack is read-only, so this is **not** worked around. `tools/context-bundle` fails
loudly with a message that names the gap (A0.30):

> `FAIL  T-6.02 declares no \`Read:\` list. A ticket with no Read list has no defined
> context — add one to the pack's ticket backlog rather than letting the agent guess.`

**The fix is a reviewed change to the pack** with a one-line reason in
`docs/pack/CHANGELOG.md` (pack `07` §9). It is the owner's to make.
