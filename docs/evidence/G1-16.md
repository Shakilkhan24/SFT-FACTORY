## The owner's review method

Two tools, both shipped for this purpose:

1. **Read the diff.** Every commit is listed below with its sha, so the review is
   `git show <sha>` — line by line, with the diff and the file side by side.

2. **Mutate the guard.** Each load-bearing rule has a **mutation harness** that breaks the
   guard on purpose and asserts the suite catches it. A rule that no harness protects is a rule
   the owner cannot trust by mutation, and the harnesses are:

   ```
   pnpm run test:mutation:artefacts      # A0.3 — the 12 elements
   pnpm run test:mutation:api            # the access-point contract
   pnpm run test:mutation:broker         # A0.1 / A0.2 — the grant and the ban
   pnpm run test:mutation:credentials     # the secret store and the redaction
   pnpm run test:mutation:gateway        # the budget and the failover
   pnpm run test:mutation:isolation      # A0.9 — the reclaim
   pnpm run test:mutation:orchestrator   # the stage runner and the resume
   pnpm run test:mutation:projections    # A0.6 — the reducers
   pnpm run test:mutation:operational-surface  # the CLI and the dashboard
   ```

   Each harness prints the mutation it made and the test that caught it. A harness that
   catches nothing would report "no mutant survived" for a rule that is not protected.

## The `tests/invariants/**` files

Thirteen files, 248 tests. Seven of them are the named invariants (INV-1, 2, 3, 5, 8, 9, 12);
the other six are the DDL, migration, state-machine, event-log and pack-oracle suites.

```
pnpm run test:invariants
```

**INV-9 is worth the owner's time in particular.** Its static half runs ESLint over a
**synthetic tree** — a provider import *outside* the gateway must FAIL the rule, the same
tree *without* the import must PASS it, and the gateway's own provider modules must not be
linted by the rule. It is the one invariant that checks a rule in **both** directions, and it
takes 90 of the suite's 107 seconds. A rule checked in only one direction would satisfy a
weaker assertion and pass every time.
